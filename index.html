Free practice questions for the Claude Certified Architect – Foundations exam

Original, scenario-based practice questions with an explanation for every answer option. 8 question sets, 120 questions. Unofficial and not affiliated with Anthropic. Enable JavaScript to use the interactive quiz.

Exam domains covered

  • Agentic Architecture & Orchestration: agent loops, subagents, hooks, retries and escalation
  • Tool Design & MCP Integration: tool descriptions, structured errors, tool_choice, MCP servers
  • Claude Code Configuration & Workflows: CLAUDE.md, rules, skills, hooks, headless CI
  • Prompt Engineering & Structured Output: few-shot prompts, JSON schemas, validation and retry, Message Batches
  • Context Management & Reliability: case facts, escalation, provenance, evaluation

Features

Practice mode and exam mode, shuffled questions, per-domain score breakdown, and progress saved only in your browser. Free, with no sign-up.
